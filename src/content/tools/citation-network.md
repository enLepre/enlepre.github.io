Start with a paper and see how it connects to the surrounding literature. Citation Network uses OpenAlex to map the works the paper cites, the papers that cite it, and related papers that draw on some of the same references.

Search for a paper to build the graph. Select a node to see the paper details and open the original source, or switch to the list view to scan the results. Citation and keyword filters help narrow the papers you are looking at.
